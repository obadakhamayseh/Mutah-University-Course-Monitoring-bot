# 🎓 بوت مراقبة مقاعد مواد جامعة مؤتة
### Mutah University Course Monitoring Telegram Bot

نظام متكامل واحترافي لمراقبة الشُعب الدراسية على موقع جريدة المواد التابع لجامعة مؤتة (`https://subp.mutah.edu.jo/`)، وإرسال تنبيهات فورية عبر تيليجرام للطلاب عند توفر مقاعد شاغرة في المواد والشُعب المغلقة.

---

## 🌟 مميزات النظام (Features)

1. **هندسة عكسية دقيقة لبوابة الجامعة (ASP.NET WebForms)**:
   - التعامل التلقائي مع رموز الحماية والتحقق: `__VIEWSTATE` و `__VIEWSTATEGENERATOR` و `__EVENTVALIDATION`.
   - إدارة جلسات كوكيز جدار الحماية (Barracuda WAF Cookies: `BNIS_*`).
   - سرعة فائقة واستهلاك منخفض للموارد عبر طلبات HTTP المباشرة (دون الحاجة لمتصفح وهمي ثقيل مثل Playwright أو Selenium).
2. **محرك منع التكرار الذكي (Deduplication Engine)**:
   - إذا اشترك 100 طالب في مراقبة نفس الشعبة، يتم إرسال **طلب فحص واحد فقط** لموقع الجامعة لكل دورة فحص!
3. **آلة حالات لمنع الإزعاج (State Machine Alerting)**:
   - الإشعار يتم **فقط** عند تحول الشعبة من حالة ممتلئة (`FULL`) إلى متاحة (`AVAILABLE`).
   - لا يتم تكرار الإشعار في الفحوصات التالية طالما أن المقاعد لا تزال متاحة، ويعاد تفعيل التنبيه تلقائياً إذا امتلأت الشعبة ثم شغر مقعد جديد.
4. **معدل استعلام آمن ومحترم (Polite Rate Limiting)**:
   - فاصل زمني (2 ثانية افتراضياً) بين كل شعبة وأخرى لتفادي الضغط على خوادم الجامعة أو حظر الـ IP.
5. **قاعدة بيانات مرنة (SQLAlchemy 2.0 Async)**:
   - دعم كامل لـ **SQLite** (تشغيل محلي فوري بدون أي تثبيت إضافي).
   - دعم كامل لـ **PostgreSQL** عبر `asyncpg` للبيئات الإنتاجية.
6. **واجهة تيليجرام تفاعلية غنية**:
   - أزرار شفافة (Inline Keyboards) لإلغاء المراقبة بضغطة زر وتحديث الحالة اللحظية وفتح رابط التسجيل مباشرة.

## 🚀 طريقة التثبيت والتشغيل (Quick Start)

### 1. المتطلبات
- بايثون 3.10 أو أحدث.
- توكن بوت تيليجرام (يمكنك إنشاءه مجاناً خلال دقيقة من البوت الرسمي [@BotFather](https://t.me/BotFather)).

### 2. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 3. ضبط ملف الإعدادات `.env`
قم بإنشاء ملف `.env` (أو عدل الملف الموجود):
```env
# ضع توكن البوت هنا:
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ

# قاعدة البيانات (افتراضياً SQLite سريعة ولا تحتاج أي إعداد):
DATABASE_URL=sqlite+aiosqlite:///./mutah_bot.db

# فترات الفحص
CHECK_INTERVAL_SECONDS=60
REQUEST_DELAY_SECONDS=2.0
```

### 4. اختبار النظام والتأكد من الاتصال
يمكنك التحقق من صحة النظام واتصاله ببوابة الجامعة وقاعدة البيانات عبر تشغيل الاختبار الآلي:
```bash
python test_system.py
```

### 5. تشغيل البوت
```bash
python run.py
```

## 🤖 أوامر البوت (Bot Commands)

| الأمر | الوصف | مثال |
|-------|-------|------|
| `/start` | بدء المحادثة وعرض رسالة الترحيب والتعليمات | `/start` |
| `/watch <المادة> <الشعبة>` | بدء مراقبة شعبة محددة وتلقي تنبيه فوري عند شغور مقعد | `/watch 0209100 1` |
| `/unwatch <المادة> <الشعبة>` | إلغاء مراقبة شعبة معينة | `/unwatch 0209100 1` |
| `/check <المادة> [الشعبة]` | فحص حي ولحظي لحالة مادة أو كافة شُعبها دون الاشتراك بالمراقبة | `/check 0209100` |
| `/list` | عرض قائمة بجميع الشعب التي تراقبها حالياً | `/list` |
| `/help` | شرح مفصل لكيفية استخدام البوت | `/help` |

## 📊 منطق فحص المقاعد (Business Logic)

```python
available_seats = capacity - enrolled

if available_seats <= 0:
    status = FULL        # الشعبة ممتلئة (تظهر في الموقع بلون أحمر)
else:
    status = AVAILABLE   # يتوفر مقاعد شاغرة (يتم إطلاق التنبيه فوراً!)
```
